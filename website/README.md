# Samir Aghayev — resume website

Static, dark-mode resume page. No build step: open `index.html` in a browser.

- `index.html` — the page
- `photo.jpg` — profile photo
- `Samir_Aghayev_CV.pdf` — downloadable CV

To host it on GitHub Pages, copy this folder into a repository named
`samiraghayev12.github.io` (or enable Pages for this folder).
